<summary>About this site (for editing)</summary>

A static site with no build step, hosted on GitHub Pages.

- `index.html`: the home page. Project cards are the `R` array, books the `B` array, articles the `A` array and short writing the `W` array, all near the bottom.
- `demos/`: the nine live demos. `articles/` and `fiction/`: one page per article and book. `covers/`: book covers (`<slug>.jpg`, 2:3). `papers/`: reports linked from project cards. `resume/`: the two PDFs.
- To add a Medium link to an article, set `m:"https://medium.com/..."` on its entry in the `A` array.
- To add the HITL confirmatory result, edit the paragraph "Where this stands" in `articles/hitl-orchestrator/index.html`.
- For a custom domain, add a `CNAME` file with the domain and set the DNS records your registrar shows.
