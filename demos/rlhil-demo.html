Learning when a human should step in.

An automated pipeline that never asks for help misses costly errors. One that always asks wastes the human. RLHIL trains a PPO agent to decide, step by step, whether to continue or intervene, using the classifier's own uncertainty.

Why a fixed threshold is not enough

A small toy pipeline (20 steps, 5 interventions allowed). Each step has a hidden risk; you only see a noisy uncertainty and a noisy risk estimate. Intervening on a real error scores +1, on a false alarm −1, and a missed error −2. Raise the difficulty and watch the best threshold move.

Limitations the paper states

The agent is trained in simulation and deployed zero-shot on real data; simulated operators stand in for real human attention; adversaries are not policy-aware; and the original MAML result (p = 0.055) needed a post-hoc reanalysis (n = 20, p < 0.001).
