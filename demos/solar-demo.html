Can you trust a detector on your own data? Label 200 items and find out.

SOLAR began as a seven-agent bot and misinformation detector. Auditing it showed most headline claims did not hold, so the project turned into methods for measuring detectors and LLM judges with a small random sample of human labels. Every number below comes from a run in the project, and each pass bar was fixed in the code before the run it judged.

Sample, label, measure

A simulated population of 4,000 items with a weak detector score. Each run draws a human-labeled sample, builds a 95% interval, and checks whether it contains the true share.

Each line is one interval, red if it missed the dashed truth. Set the AUC to 0.5: the interval stays valid and simply gets no help from the detector. In the report, 200 labels gave coverage 0.94 to 0.96 across ten datasets.

Audit one item at a time and check the dashboard after every label. An ordinary interval cries wolf; a confidence sequence is built to be watched continuously.

Teal band: confidence sequence, valid at every look. Dashed amber lines: ordinary Wilson interval. An alarm fires when the lower bound passes the agreed rate, from item 10. Set the rate after equal to the rate before to see false alarms. The band is about 1.5 times wider, and a real 8.6-point rise took about 500 labels to flag at the median.

GPT-4 agrees with humans 75.5% of the time. If the two judges’ errors were independent, a 70.1% judge predicts 43% GPT-4 error on disagreements; the observed 41.8% matched. A weaker judge flags its own mistakes more than the stronger one’s.

What the page cannot show

Every simulation treats a dataset’s own label as the human reviewer, and real reviewers err. The pilot planner’s 6% gain is in-sample: it was designed after seeing the three text datasets. The monitoring evidence uses bootstrap streams with mostly constructed shifts, and the demos above are fresh random draws that land near the report’s figures, not on them. The BotShare tool withholds its headline number because both model profiles failed its reliability bar.
